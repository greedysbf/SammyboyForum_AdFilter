Spam filter for sammyboy forum. Used by uBlock Origins to block advertising and point trading threads.

How to use:
1. Open uBlock Origins
2. Go to Dashboard
3. Go to Filter Lists
4. Scroll down to "Import"
5. Paste the URL "https://greedysbf.github.io/SammyboyForum_AdFilter/sbfadspam.txt" into the import text box
6. Click "Apply Changes" at the top left corner

How to remove:
1. Open uBlock Origins
2. Go to Dashboard
3. Go to Filter Lists
4. Scroll down to "Custom"
5. Click the <img src="https://raw.githubusercontent.com/FortAwesome/Font-Awesome/6.x/svgs/solid/crown.svg" width="50" height="50"> icon beside "SBF Advertiser Spam Blocker
" to delete the filter list
